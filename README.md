numpy, matplotlib required

Two independent projects. Each folder runs on its own.

- `single_qubit/`: 1-qubit simulator (`qubit_sim.py`)
  - `python single_qubit/test_qubit_sim.py`
- `grover_search/`: n-qubit simulator (`multi_qubit.py`) and Grover's search (`grover.py`)
  - `python grover_search/test_grover.py`
  - `python grover_search/grover_demo.py` (saves `grover_success.png` in the current directory)
